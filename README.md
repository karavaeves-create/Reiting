# Telegram Mini App — рейтинг вожатых

## Возможности
- Общий рейтинг с синхронизацией в реальном времени.
- Кнопки +1, +2, +3 и исправление -1.
- История начислений.
- Только Telegram ID из ADMIN_IDS могут менять баллы.
- Подпись Telegram initData проверяется на сервере.

## 1. Создайте бота
Откройте https://t.me/BotFather, отправьте /newbot, следуйте инструкциям и сохраните токен. Узнайте числовой Telegram ID свой и выбранных организаторов. Токен бота не публикуйте и никому не пересылайте.

## 2. Разместите проект
Нужен Node.js-хостинг с HTTPS и постоянным диском. В этом проекте предусмотрен Render Starter с постоянным диском. Документация: https://render.com/docs/web-services и https://render.com/docs/disks.
1. Создайте приватный репозиторий на https://github.com/new.
2. Распакуйте ZIP и загрузите содержимое в репозиторий.
3. В Render подключите репозиторий через Blueprint (используется render.yaml).
4. В настройках сервиса задайте секрет BOT_TOKEN (токен BotFather) и ADMIN_IDS — числовые ID через запятую, например 123456789,987654321.
5. Дождитесь HTTPS-адреса вида https://имя-сервиса.onrender.com.

## 3. Подключите мини-приложение
В @BotFather выберите своего бота → Bot Settings → Menu Button → Configure menu button. Вставьте HTTPS-адрес Render и название «Рейтинг». Откройте кнопку меню бота.

## 4. Важные замечания
- Начальный список — 21 человек из последней согласованной таблицы, с указанными там баллами. Если нужно добавить/убрать людей, отредактируйте массив seed в server.js. После создания базы изменения seed не обновляют уже существующую базу.
- Список администраторов меняется в переменной окружения ADMIN_IDS на хостинге, а не через интерфейс.
- В текущем интерфейсе есть начисление и уменьшение на 1 балл, но нет сброса всей базы.
- Нужен хостинг с постоянным диском, иначе файл с результатами может исчезнуть при перезапуске/деплое.
- Telegram требует HTTPS для Mini Apps. Официальная документация: https://core.telegram.org/bots/webapps.

## Локальный запуск
Нужен Node.js 20+:
```bash
npm install
BOT_TOKEN="токен" ADMIN_IDS="ваш_telegram_id" npm start
```
Для реального использования приложение надо открыть из Telegram по HTTPS.
